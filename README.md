# Parking App Guatemala

Marketplace de parqueos para Guatemala (buscar, reservar y pagar parqueo desde el celular), inspirado en SpotHero.

## Estado

Fase 0: investigación de mercado y plan de desarrollo. Todavía no hay código.

## Contenido del repo

- `research_notes/` — notas de investigación por tema (competidores, operadores de parqueos, apps globales, apps en Latinoamérica, contexto local de pagos/regulación/tecnología).
- `reports/` — informe consolidado de investigación de mercado.
- `docs/` — plan de desarrollo del producto (visión, MVP, arquitectura, roadmap).
